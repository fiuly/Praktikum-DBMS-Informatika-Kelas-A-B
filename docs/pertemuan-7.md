## Instruksi Pelaksanaan

Pertemuan ke-7 dialokasikan khusus untuk **Responsi** (Ujian Praktikum) guna mengevaluasi pemahaman praktikan terhadap materi yang telah dipelajari dari pertemuan-pertemuan sebelumnya, mulai dari perancangan DDL, eksekusi DML dasar, hingga Basic dan Advanced Queries.

:::info Akses Soal dan Ketentuan
Silakan cek **Google Classroom kelas masing-masing** untuk mendapatkan:
1. File dataset, panduan, dan **Soal Responsi**.
2. Rincian **Ketentuan Khusus** dari asisten pengampu kelas.
3. Informasi **Batas Waktu (Deadline)** pengerjaan.
4. Tempat *upload* / pengumpulan lembar jawaban (biasanya dalam format `.sql` atau `PDF` beserta *screenshot* hasil eksekusi sesuai instruksi).
:::

### Ketentuan Umum
Untuk kelancaran pelaksanaan responsi, harap perhatikan hal-hal berikut:
1. **Persiapan Platform:** Pastikan *services* Apache dan MySQL/MariaDB pada Laragon kalian sudah berjalan lancar sebelum waktu pengerjaan dimulai.
2. **Kejujuran Akademik:** Kerjakan soal murni secara mandiri. Segala bentuk kecurangan atau plagiarisme akan ditindak tegas sesuai kontrak kuliah praktikum.
3. **Format Pengumpulan:** Perhatikan baik-baik instruksi penamaan file (contoh: `NIM_Nama Lengkap_ResponsiDBMS.sql`) agar file jawaban kalian tidak tercecer.
4. **Kendala Teknis:** Apabila mengalami kendala sistem yang di luar kendali (*force majeure*) saat pengerjaan berlangsung, segera konfirmasi dan laporkan ke asisten pengampu kelas masing-masing beserta buktinya.
