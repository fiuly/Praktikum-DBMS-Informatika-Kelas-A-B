## Instruksi Pelaksanaan Lab

Pertemuan ke-6 dialokasikan secara khusus untuk **Lab Session 2**. Pada sesi ini, temen-temen praktikan akan berlatih dan mempraktikkan langsung materi *Basic Query* (seperti `SELECT`, `WHERE`, `JOIN`, `GROUP BY`, dll) yang sudah dipelajari pada pertemuan sebelumnya.

:::info Akses Modul dan Tugas Lab
Silakan cek **Google Classroom kelas masing-masing** untuk mendapatkan:
1. File dataset dan skema database (SQL) yang akan digunakan selama sesi lab ini.
2. Modul panduan dan **Soal Latihan Lab**.
3. Rincian tugas dan **Batas Waktu (Deadline)** pengumpulan.
4. Tempat *upload* / pengumpulan hasil latihan (biasanya berupa file `.sql` beserta *screenshot* hasil eksekusi query sesuai instruksi asisten).
:::

### Ketentuan Umum
Untuk kelancaran sesi lab, perhatikan hal-hal berikut:
1. **Persiapan Platform:** Pastikan *services* Apache dan MySQL/MariaDB pada Laragon kalian sudah aktif sebelum sesi lab dimulai.
2. **Pengerjaan:** Kerjakan latihan sesuai instruksi yang diberikan oleh asisten di kelas. Jangan ragu untuk *raise hand* atau bertanya jika mengalami *error* atau ada query yang membingungkan.
3. **Format Pengumpulan:** Perhatikan baik-baik instruksi penamaan file dari asisten pengampu (contoh: `NIM_Nama Lengkap_Lab2.sql`) agar tugas kalian mudah direkap.

*Selamat berlatih dan bereksplorasi dengan query!*
